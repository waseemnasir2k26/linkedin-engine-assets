# linkedin-engine-assets

Public image host for a LinkedIn campaign run from the private `linkedin-engine` repo. Scheduling CSVs reference these files by raw URL because the scheduler needs publicly reachable image links.

| Folder | Contents |
|---|---|
| `day01/` | 8 carousel slide PNGs |
| `day02/` | 1 single-image card |
| `day04/` | 1 photo |
| `day06/` | 10 carousel slide PNGs |
| `day08/` | 1 single-image card |
| `week2/` | 7 week-2 post images |

Asset-only repo: no code, no build. File names are campaign-day based, so these assets only make sense inside that one campaign.
